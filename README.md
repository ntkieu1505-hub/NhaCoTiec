# Nhà Có Tiệc – Project Overview

This repository contains a wedding invitation web application built with Vite + React + TypeScript.

## New Feature: Gemini AI Chat Widget

A floating chat widget (`ChatBotWidget`) has been added to provide instant AI‑driven customer consultation using **Gemini API**.

### Files Added
- `src/services/geminiChatService.ts` – wrapper around the Gemini REST endpoint. The API key is read from the environment variable `REACT_APP_GEMINI_API_KEY`.
- `src/components/ChatBotWidget.tsx` – React component that renders a floating chat button, opens a modal dialog, and displays the conversation.
- Updated `src/app/App.tsx` to render `<ChatBotWidget />` globally.

### Installation Steps
1. **Install Gemini API plugin** (already done):
   ```bash
   npm i @gemini-ai/plugin-api
   ```
2. **Install project dependencies** (if not already):
   ```bash
   npm install
   ```
3. **Add a `.env` file** in the project root (same level as `package.json`):
   ```dotenv
   REACT_APP_GEMINI_API_KEY=YOUR_GEMINI_API_KEY_HERE
   ```
   > The key can be obtained from the Gemini Console. Do **not** commit this file.
4. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in a browser. You should see a blue chat button at the bottom‑right corner.
5. **Test the widget** – click the button, type a question (e.g., "Bạn có mẫu thiệp gì?"), and press **Gửi**. The response will appear in the chat window.

### Build for Production
```bash
npm run build
```
The widget is bundled automatically with the rest of the app.

### Known Limitations
- The API key is shipped to the client bundle; make sure you only use a restricted key suitable for front‑end usage.
- CORS errors may appear if the key is invalid or the request quota is exceeded.

# Nhà Có Tiệc

## 1. Giới thiệu dự án

Nhà Có Tiệc là dự án xây dựng nền tảng thiệp cưới điện tử, cung cấp giải pháp tạo và đặt thiệp cưới trực tuyến. Bên cạnh website, dự án tích hợp các trợ lý AI nhằm hỗ trợ tư vấn khách hàng và tự động hóa quy trình thu thập, phân tích nội dung trên mạng xã hội.

Dự án bao gồm 3 sản phẩm chính: Website Nhà Có Tiệc và 2 AI Agent được xây dựng trên nền tảng n8n.

## 2. Sản phẩm triển khai

### 2.1. Website Nhà Có Tiệc

Website giới thiệu và cung cấp dịch vụ thiệp cưới điện tử, cho phép khách hàng tham khảo các mẫu thiệp, lựa chọn sản phẩm và đặt hàng trực tuyến.

**Chức năng chính:**
- Giới thiệu dịch vụ và các mẫu thiệp cưới điện tử.
- Hiển thị thông tin chi tiết các mẫu thiệp.
- Hỗ trợ khách hàng lựa chọn mẫu thiệp phù hợp.
- Tiếp nhận thông tin và yêu cầu đặt hàng.
- Tích hợp Gemini AI Chat Widget hỗ trợ tư vấn khách hàng trực tiếp trên website.

### 2.2. AI Agent 1 – Trợ lý AI Nhà Có Tiệc

**Mục đích:**

Xây dựng trợ lý AI hỗ trợ tư vấn khách hàng về dịch vụ thiệp cưới điện tử, giải đáp thắc mắc và ghi nhận thông tin khách hàng, góp phần tự động hóa hoạt động tư vấn và chăm sóc khách hàng.

**Chức năng chính:**
- Tiếp nhận và xử lý tin nhắn của khách hàng.
- Tư vấn thông tin về các mẫu thiệp điện tử.
- Giải đáp các câu hỏi thường gặp (FAQ).
- Tra cứu thông tin thiệp thông qua công cụ được tích hợp.
- Ghi nhận và lưu trữ thông tin khách hàng trên Google Sheets.
- Gửi thông báo đến nhân viên phụ trách thông qua Telegram.

**Quy trình hoạt động:**

Tiếp nhận tin nhắn → Phân tích yêu cầu bằng AI Agent và AI Skills → Gọi công cụ phù hợp → Trả lời khách hàng → Lưu thông tin và thông báo cho nhân viên khi cần thiết.

### 2.3. AI Agent 2 – Workflow Tổng hợp Content và Video TikTok

**Mục đích:**

Tự động thu thập, sàng lọc và phân tích các video TikTok thuộc lĩnh vực thiệp cưới, từ đó đề xuất ý tưởng nội dung phù hợp phục vụ hoạt động truyền thông của Nhà Có Tiệc.

**Chức năng chính:**
- Tự động chạy workflow hằng ngày vào lúc 20h.
- Sử dụng Apify để thu thập khoảng 20 video TikTok thông qua các hashtag liên quan đến thiệp cưới.
- Sàng lọc video có từ 10.000 lượt xem trở lên.
- Lưu trữ thông tin video gồm đường link, caption, lượt xem, lượt thích, tên kênh và ảnh bìa trên Google Sheets.
- Sử dụng Google Gemini để phân tích 5 video nổi bật nhất.
- Đề xuất 3 ý tưởng content dựa trên kết quả phân tích.

- Nội dung đề xuất bao gồm tiêu đề, kịch bản, caption và hashtag.
- Lưu kết quả ý tưởng content vào tab riêng trên Google Sheets.

**Quy trình hoạt động:**

Kích hoạt theo lịch → Apify thu thập video TikTok → Sắp xếp và lọc video → Lưu dữ liệu vào Google Sheets → Gemini phân tích 5 video nổi bật → Tạo 3 ý tưởng content → Lưu kết quả.
